Linux, Kernel and Infrastructure Updates (2026-11-09)

This week's edition covers critical security updates, kernel developments, and major build system releases. We also highlight practical tooling and distribution changes impacting administrators and developers.

Alpine Linux Security Advisory: OpenSSH-server password authentication bypass

Alpine Linux has released a security advisory regarding a password authentication bypass in OpenSSH-server. Administrators running affected OpenSSH services on Alpine should review the advisory and apply necessary patches immediately. via Hacker News

Microsoft's Azure Linux 3.0.2022 Ships With More Than 470 Security Fixes

Microsoft released Azure Linux 3.0.2022, delivering security patches across components in its distribution. The release incorporates fixes for more than 470 CVEs identified across its bundled open-source packages. via Phoronix

Two stable kernels for Friday

Greg Kroah-Hartman released the 7.3.2 and 6.18.61 stable Linux kernels containing fixes across the tree. Users and system operators are advised to upgrade to maintain system stability and security. via LWN.net

Automake 1.20 Brings New Features, Desires To Re-Establish GNU As Leading Build System

GNU Automake 1.20 has arrived with a transition to GPLv3+ licensing and a new --enable-jobserver option. The update aims to modernize build management and performance across projects relying on the GNU build system. via Phoronix

Linux 7.4-rc2 Released With FAT32 Optimization, AMDGPU HDMI 2.2 Improvement

Linus Torvalds released Linux 7.4-rc2, bringing early post-merge-window bug fixes. The release includes specific optimizations for the FAT32 filesystem and improvements for AMDGPU HDMI 2.2 setups. via Phoronix

Linux Developers Look To Drop RT_GROUP_SCHED As It's "Broken Beyond Repair"

Linux kernel developers are evaluating the removal of RT_GROUP_SCHED, citing that the feature is broken beyond repair. If dropped, this change will affect how real-time tasks are scheduled within cgroups. via Phoronix

[$] User namespaces + file capabilities = trouble

A patch series from Josef Bacik seeks to resolve privilege containment flaws where user namespaces interact with file capabilities. The effort aims to strengthen the security model of containers relying on user namespaces to isolate root access. via LWN.net

FreeBSD 15.2 Beta 1 Allows Experimental Cross-Building Of Base Packages On Linux/macOS

FreeBSD 15.2 Beta 1 is now available for testing ahead of the final point release. Notably, this version introduces experimental support for cross-building FreeBSD base packages directly on Linux and macOS hosts. via Phoronix

[$] Plasma X11 session removal surprises some Fedora users

KDE Plasma 6.8 dropped support for X11 sessions, following up on plans established with Plasma 6.7. This deprecation impacts users relying on legacy X11 sessions on recent distributions like Fedora. via LWN.net

The Ubuntu 26.04 Rust sudo is not compatible with standard sudo

Discussions have surfaced regarding compatibility discrepancies between standard sudo and the Rust-based sudo implementation planned for Ubuntu 26.04. System administrators should prepare for behavioral differences that may impact automated workflows and administrative scripts. via Hacker News
