Linux, Tooling, and Self-Hosting Updates: Week in Review (2026-11-16)

This week's roundup features significant infrastructure advancements, from integrated storage RAID implementations to virtualization performance improvements. Developers and self-hosters also gain notable updates in toolchains, hardware drivers, and terminal workflows.

Announcing XRAID: declustered parity RAID for zoned XFS

Christoph Hellwig announced the initial release of XRAID, bringing declustered parity RAID natively into the XFS file system. It specifically targets parity RAID on zoned devices like SMR drives while eliminating data integrity issues and offering write speeds up to 20 times faster on SSDs. via LWN.net

Zellij 0.46 released

Zellij 0.46 has been released, introducing a standalone desktop terminal mode executable via the CLI alongside its traditional multiplexer capabilities. The update also adds a GUI settings screen while ensuring terminal sessions can still be shared seamlessly across environments. via LWN.net

Red Hat Working To Improve Memory Tiering For QEMU VMs To Save RAM

Red Hat engineers are developing enhanced memory tiering solutions for QEMU virtual machines to mitigate high RAM costs. The initiative aims to leverage NVMe SSDs to store VM memory across a wider variety of virtualization scenarios. via Phoronix

Rust 1.100.0 released

The Rust language has reached version 1.100.0, introducing long-awaited features to its standard library and toolchain. Highlights include the stabilization of the 'never' type, initial core pieces of the Allocator API, and Cargo reporting for unused dependencies. via LWN.net

Modern NTFS Driver Gaining O_TMPFILE Support With Linux 7.5

The modern open-source Linux NTFS read/write driver is gaining O_TMPFILE support ahead of the Linux 7.5 kernel cycle. This improvement enhances how the driver handles temporary file creation, building upon recent driver rewrites. via Phoronix

NVIDIA Highlights Their Open-Source vGPU Upstreaming Work Built Atop Nova

NVIDIA presented progress on upstreaming open-source vGPU capabilities built directly on top of the Nova Rust-based kernel driver. This effort aims to transition functionality away from out-of-tree drivers into the mainline Linux kernel. via Phoronix

IBM Talks Up Their New Ability For Handling ARM64 Guest VMs on s390 Hardware

IBM and Arm's collaborative dual-architecture hardware effort has landed initial virtualization support, enabling ARM64 guest VMs on s390 hardware via Linux KVM. Initial patches have been merged into Linux 7.4 to facilitate cross-architecture workloads. via Phoronix

Fwupd 2.1.10 Brings Fixes, New Synaptics Touchpad Supported

Fwupd 2.1.10 is out as the newest stable release for Linux firmware updates, bringing bug fixes and hardware enablement for new Synaptics touchpads. It continues to streamline device management for system administrators handling peripheral firmware upgrades. via Phoronix

Dasharo ACPI Fan Control Linux Driver Posted For Adjusting Fan Curves

Firmware consultancy 3mdeb posted a new Linux kernel driver designed to support fan curve adjustments on hardware running open-source Dasharo firmware. This provides open firmware users on select MSI and Gigabyte platforms direct OS-level thermal controls. via Phoronix

Cloudflare Open Sources Kitesurf: Their Web Browser For AI Agents

Cloudflare has officially open-sourced Kitesurf, their dedicated stateless web browser engineered specifically for AI agents. The release offers developers a dedicated, lightweight browser architecture intended for programmatic and automated web interactions. via Phoronix
