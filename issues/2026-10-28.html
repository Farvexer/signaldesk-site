Linux 7.4 Merge Window, Systemd Adopts Rust, and KeePassXC 2.8.0 (2026-10-28)

This week's updates highlight significant foundational progress across the Linux kernel and critical system utilities. Key developments include Rust integration in systemd leaf components, major driver hardening, and expanded hardware enablement.

Systemd adds support for components written in Rust

Systemd has merged initial support allowing new leaf components to be developed in Rust. Core system components will remain in C and existing code will not be ported, but this marks the beginning of Rust adoption within the project. via LWN.net

Linux 7.4 Introduces DMA-BUF Support To I/O Path With IO_uring

Infrastructure providing DMA-BUF support within the kernel's I/O path via the IO_uring framework has been merged into Linux 7.4. This allows for zero-copy data transfers and more efficient buffer sharing across devices. via Phoronix

KeePassXC 2.8.0 released

KeePassXC 2.8.0 has been released, transitioning the UI framework from Qt5 to Qt6. The update also delivers Auto-Type functionality for Wayland users on Linux, Polkit-based quick unlock, and remote database synchronization. via LWN.net

NTFS3 Hardened In Linux 7.4 Against Corrupted Or Maliciously-Crafted NTFS Volumes

Paragon Software has submitted updates for Linux 7.4 hardening the in-kernel NTFS3 read/write driver. These improvements help protect host systems from crashes or exploits when mounting corrupted or maliciously crafted NTFS partitions. via Phoronix

[$] The end of __get_user() and __put_user()

Linus Torvalds authored and merged a 48-part patch series targeting Linux 7.4 to retire the legacy __get_user() and __put_user() primitives. The series cleans up decades-old user-space memory access mechanisms in favor of modern, safer kernel alternatives. via LWN.net

Accelerating HTTP Web Servers With In-Kernel eBPF Deliver Up To 4.5x Throughput

A new research project called Beeper implements application-layer HTTP parsing and caching directly in the Linux kernel using eBPF. Benchmarks indicate that handling web requests via in-kernel eBPF can improve server throughput up to 4.5 times under high loads. via Phoronix

[$] Python's experimental JIT to be removed

CPython's experimental JIT compiler, originally introduced in Python 3.13, is being slated for removal. The Python steering council paused ongoing work in the main branch pending a finalized PEP detailing its architectural direction. via LWN.net

Linux 7.4 Begins Employing New "Core MM" Tree

Linux kernel maintainers have split core memory management patches out of Andrew Morton's traditional MM branch into a dedicated 'Core MM' tree starting in Linux 7.4. This new development tree aims to streamline the review and integration of fundamental virtual memory subsystem updates. via Phoronix

Linux 7.4 Expands Sensor Monitoring For More ASUS & MSI Motherboards, New Minisforum Driver

The HWMON subsystem pull for Linux 7.4 incorporates a new Minisforum driver alongside expanded hardware monitoring support for multiple ASUS and MSI motherboards. Systems administrators running newer desktop and small-form-factor hardware will gain more reliable native sensor readouts. via Phoronix

Robinson: Raspberry Pi 5 on Fedora

Fedora contributor Peter Robinson detailed support for Raspberry Pi 5 hardware, noting that Fedora 45 will work across all Raspberry Pi Model 5B variants. Early adopters on Fedora 44 currently require boot workarounds that are resolved by pulling the latest kernel and firmware packages. via LWN.net
