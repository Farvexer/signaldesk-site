# Linux & Open-Source News: OpenSSH Flaw, Kmorph Recovery, and Linux 7.4 Updates (2026-11-08)

This week's highlights cover critical security updates alongside performance improvements across the Linux kernel and storage layers. Practitioners will also find key updates regarding server crash recovery, image-based OS architectures, and local AI hosting tools.

### [Critical security vulnerability affects OpenSSH on Alpine Linux systems](https://lwn.net/Articles/1105464/)
OpenSSH version 10.6p2 has been released with a workaround for a critical security vulnerability affecting Linux distributions that combine musl libc with PAM disabled, such as Alpine Linux. Administrators running impacted systems are advised to apply the update or disable password authentication immediately to secure their hosts.
*via LWN.net*

### [Kmorph Aims To Provide Rebootless Linux Kernel Crash Recovery](https://www.phoronix.com/news/Kmorph-Linux-Crash-Recovery)
Kmorph is a new project designed to deliver reboot-less Linux kernel crash recovery. The tooling aims to reduce service interruption down to roughly two seconds of downtime for critical daemons such as the Nginx web server following a kernel crash.
*via Phoronix*

### [Amutable Foundations: A Technical Overview](https://lwn.net/Articles/1105934/)
Lennart Poettering, Michael Vogt, and Joaquim Rocha detailed the technical architecture of the Amutable Operating System (AOS). The design employs an image-based OS structure intended to enforce strict security properties beyond traditional mutable Linux installations.
*via LWN.net*

### [Linux's RAID6 Check Tool Sees 3x Performance Via Batching](https://www.phoronix.com/news/Linux-3x-Faster-raid6check)
The raid6check utility for Linux MD RAID6 arrays has integrated batching optimizations into its codebase. Practitioners maintaining software RAID setups can expect up to a 3x performance increase when checking and repairing array errors.
*via Phoronix*

### [Linux 7.4-rc2 Change Yields As Much As 162x Improvement For FAT32](https://www.phoronix.com/news/Linux-7.4-rc2-FAT32)
Non-MM fixes merged into Linux 7.4-rc2 introduce major FAT32 performance optimizations, demonstrating up to a 162x improvement in certain operations. This follows an earlier 265x improvement merged for the 7.4 cycle, benefiting storage operations on FAT32 volumes.
*via Phoronix*

### [AMD-Backed Lemonade Local AI Server Ships Redesigned Desktop App & Web UI](https://www.phoronix.com/news/Lemonade-2026.45.3)
The AMD-backed Lemonade local AI server released version 2026.45.3, featuring a redesigned web UI and desktop application. Self-hosters looking for turnkey local model execution have an updated interface for managing workloads.
*via Phoronix*

### [Seven stable kernels with fixes for three Xen vulnerabilities](https://lwn.net/Articles/1105902/)
Greg Kroah-Hartman released stable kernel updates covering branches 7.3.3, 6.18.62, 6.12.116, 6.6.162, 6.1.192, 5.15.225, and 5.10.274. These coordinated point releases specifically address three Xen vulnerabilities across all supported series.
*via LWN.net*

### [Zlib 1.4 Released With More Than One Dozen Security Fixes](https://www.phoronix.com/news/Zlib-1.4-Released)
Zlib 1.4 has officially been released for the foundational compression library. System maintainers should note that the release incorporates more than a dozen security fixes addressing various reported vulnerabilities.
*via Phoronix*

### [Ubuntu Moving Ahead With Plans For Splitting Up Linux-Firmware, HWE Option](https://www.phoronix.com/news/Ubuntu-Going-With-Firmware-HWE)
Ubuntu is moving forward with plans to divide its monolithic linux-firmware package and introduce a hardware enablement (HWE) firmware option targeted for Ubuntu 27.04. The change aims to simplify firmware updating and may eventually be backported via SRU to Ubuntu 26.10 and 26.04 LTS.
*via Phoronix*

### [Bazzite 45 released](https://lwn.net/Articles/1105395/)
Bazzite 45, an image-based gaming distribution built on Fedora, is now available rebased on Fedora 45. The update ships with updated Open Gaming Collective kernels and adds support for Logitech TrueWheel hardware.
*via LWN.net*
